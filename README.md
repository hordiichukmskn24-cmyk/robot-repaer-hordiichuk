### 1. Виконані завдання:
- Налаштовано базову сцену `MainScene` та додано ортографічну кабінетну камеру[cite: 1].
- Створено та налаштовано об'єкт персонажа (`PlayerCharacter`)[cite: 1, 4].

- Використано нову систему введення (**Input System**) з композитними прив'язками для клавіш **WASD** та **стрілок**[cite: 1].
- Забезпечено незалежність швидкості руху від частоти кадрів за допомогою `Time.deltaTime`[cite: 1].
- Створено покриття підлоги за допомогою **Tilemap** та налаштовано палітру тайлів (`Tile Palette`)[cite: 1, 3].

### 2. Вирішені проблеми та технічні нюанси:
- **Шар відображення (Order in Layer):** Налаштовано порядок шарів (`Order in Layer = -10` для Tilemap та `0` для Sprite Renderer), щоб персонаж не пропадав під текстурами підлоги[cite: 1].
- **Розмір тайлів (Pixels Per Unit):** Виставлено значення `Pixels Per Unit = 64` для спрайтів підлоги, щоб прибрати графічні артефакти та щілини між плитками[cite: 1].
- **Синхронізація з GitHub:** Налаштовано завантаження проєкту через **GitHub Desktop** замість веб-інтерфейсу браузера через обмеження на кількість файлів[cite: 1, 6].
